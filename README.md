# 爆款视频脚本AI

纯 HTML、CSS、JavaScript 本地演示。无需安装依赖、构建、注册或 API Key。

## Windows 启动

双击本文件夹中的 `index.html`，使用 Edge 或 Chrome 打开。也可在本文件夹打开 PowerShell：

```powershell
Start-Process .\index.html
```

本地文件模式的地址为 `file:///.../index.html`，没有端口。

如已安装 Python，可用本地 HTTP 模式：

```powershell
python -m http.server 8765 --bind 127.0.0.1
```

然后打开 http://127.0.0.1:8765/ 。按 Ctrl+C 停止。本次电脑也有随附 Python，可使用：

```powershell
$projectPython = Join-Path $env:USERPROFILE '.cache\codex-runtimes\codex-primary-runtime\dependencies\python\python.exe'
& $projectPython -m http.server 8765 --bind 127.0.0.1
```

服务器只提供静态页面，不接收上传、不保存或分析视频。若端口被占用，可改用 8766，并打开对应地址。

## 产品首页

`index.html` 仅作为产品介绍首页，包含核心价值、三步使用流程、功能展示、静态示例、套餐预览和 FAQ。生成表单与结果已移至独立的 `workspace.html`，首页“进入工作台”等创作入口会跳转到该页面；“使用示例开始创作”会在工作台调用原有示例填充，不自动生成。手机首页使用可展开导航，工作台提供创作与历史导航。

首页不加载生成引擎、视频预览或 Office 导出脚本；这些仅由工作台加载。旧的 `index.html#generator`、`/#generator` 和旧历史回填链接会自动转到工作台，保留历史参数。历史页、登录和注册演示页的创作入口也已统一指向工作台。无须登录即可体验，不做真实认证拦截。首页套餐预览与独立套餐页使用教学演示数据，没有真实订阅或支付。

## 登录与注册表单演示

首页导航的“登录”打开 `login.html`，可前往 `register.html`。两个页面均为前端演示：校验必填、邮箱格式、8—128 字符的测试密码；注册额外校验两次密码一致。密码支持显示与隐藏，校验通过或离开页面时清空密码。“忘记密码”只展开未接入说明，不发送邮件。

表单不发送数据、不保存邮箱或密码、不创建账号或认证状态。校验通过仅代表格式有效，页面会明确提示。请使用虚构测试信息，不要输入真实密码；工作台仍无需登录即可使用。关闭 JavaScript 时表单禁用，避免意外提交。`auth.css` 和 `auth.js` 分别管理两个页面的专用样式与交互。

## 用户中心演示

首页和工作台导航的“用户中心”打开 `account.html`。默认头像、昵称“灵感创作者”、`demo@example.com`、120 积分、免费演示版套餐及本月 12 次生成均为固定模拟数据；不与登录表单、本机历史或实际生成次数关联，不进行真实认证，也不存储账户信息或扣除积分。

“查看升级套餐”跳转到独立的 `pricing.html` 教学套餐页，没有真实购买或支付流程。账户操作区可查看登录、注册演示和账户数据说明；没有修改邮箱、密码或删除账号等未接入操作。页面使用 `account.css`，除共用按钮光效外，不需要额外 JavaScript。

## 使用

1. 可选：选择本地 MP4，最大 200 MB；支持预览、替换和移除，不上传。
2. 填写主题（必填），选择类型、平台、5—600 的整数秒和比例。
3. 描述自有素材、手动参考特点和其他要求；留空标记为待补充。可补充旁白或口播文案，建议按句换行。提供文字不代表已有录音。
4. 也可点击“一键填入示例”，仅填表，不替换或添加视频。
5. 点击“生成分镜脚本”，右侧按表格逐镜列出时间、画面、旁白、字幕和剪辑说明。画面、旁白、字幕及剪辑说明的单元格可直接编辑；时间只读，保持时长合计正确。
6. 镜头列的“复制此镜”只复制这一镜的时间、画面、旁白、字幕和剪辑说明；“复制全部脚本”使用当前表格内容，连同创作依据与统一要求复制为完整文字。两者均包含手动编辑的内容；“创作依据、配乐与待补充信息”可展开查看。
7. “导出”展开格式菜单，选择“导出表格”或“导出文档”，两种格式均使用当前已编辑内容。Excel（.xlsx）自动设置列宽、按内容估算行高、自动换行、表头和隔行底色、边框、筛选、冻结前五行和镜头列，包含主题、平台、比例、目标时长及每镜九列数据。Word（.docx）采用 A4 纵向，按镜头分块排版，重复镜头表头，长内容允许自动分页，包含创作依据、统一要求和页码。可用 Office / WPS 打开。
8. 重新生成保留全部需求表单，切换两套结构建议并调整未指定的分镜数量、时间与节奏；会覆盖表格中的手动修改。
9. 示例按钮下方的“历史记录”打开历史页。默认展示明确标注的固定模拟记录，可体验详情、复制、再次生成和空状态；示例不会写入本机历史。切换“本机记录”可继续查看当前浏览器的最近 20 份脚本。生成时自动保存，编辑后短暂延迟保存，不保存视频。存储受限或空间不足会提示保存失败；清除网站数据会丢失本机记录。

历史页的“结果数量”按“1 份脚本 · 若干镜头”展示。“再次生成”仅回填需求，不自动提交：模拟记录可回填完整示例输入；旧本机记录没有保存完整原始需求，只回填主题、类型、平台、时长与比例，并提示补充素材等信息。找不到记录时显示提示，不编造旧输入。原有生成规则未改动；模拟详情是固定脚本，重新生成的镜头数量可能不同。“体验空状态”仅切换视图，不删除任何数据。本阶段没有数据库或删除操作。

自动复制受限时会尝试兼容复制，仍失败则选中正文供 Ctrl+C 或手机长按复制。

### 工作台演示状态

初次打开显示空状态，主题为空或时长无效会定位到对应字段。有效提交后会短暂显示约 0.8 秒的“模拟生成中”，期间暂时锁定输入与结果操作，防止重复提交；这只是本地交互演示，不是 AI 请求或视频分析，也不扣费。

勾选生成按钮附近的“下次模拟失败”，再点击生成或重新生成，即可体验错误状态。开关触发一次后自动关闭；失败不覆盖已有脚本、不新增历史记录，输入也会保留。点击“重试生成”会再次使用当前表单生成。清空输入只清空文字，保留类型、平台、时长、比例、视频及已有结果；重新生成成功仍会覆盖表格中的手动修改。

## 规则与限制

- 不接真实 AI，不理解对标视频，不剪辑、渲染或导出视频。
- 用户手动要求原样保留并优先于默认建议；复杂自然语言不能完整解析，执行前需要复核。
- 识别“开头5秒”“主体20秒”“结尾5秒”“前3秒”等阿拉伯数字时长，分配其余部分。冲突时标明待确认，并暂按目标总时长安排。
- 五类内容各有两套结构：口播、产品展示、探店、知识分享、生活记录。
- 开头、主体、结尾继续细分为带连续时间段的镜头，总时长不变。较长视频会生成更多镜头。
- 素材描述按标点简单分隔为候选片段，按描述顺序粗排；不理解实际画面。描述中的秒数只用于估算可用长度，不代表已验证视频时长。长度不足的位置标为待补充；未知长度需要确认，不自动循环凑时长。
- 旁白文案按句分配，保持原文顺序。未提供文案时不编造对白；明确不要人声时不安排旁白。只有文案没有音频时提示补录或确认，时长与语速需要试听。
- 字幕草案来自主题、素材描述或提供的旁白；执行前确认与画面吻合，不代表事实核验结果。
- 画面建议以实际素材为前提，未知信息待补充，不假装已经识别画面。
- 部分 MP4 编码可能无法播放，页面会提示尝试 H.264 编码的 MP4。
- 刷新后工作台不保留表单、结果和视频；已保存脚本可在历史记录中查看。历史记录使用浏览器 localStorage，无登录、数据库、支付或后台存储。
- 导出在浏览器本地完成，不发送到服务器。下载文件名按生成时的主题命名；修改左侧表单后应重新生成，才能更新结果及导出信息。
- Word 字体替换、分页和打印效果会随 Office/WPS 版本变化；当前已检查实际下载文件结构和长文字完整性，因本机缺少 LibreOffice，尚未完成文档页面渲染与桌面 Word/WPS 的视觉验证。
- 超长文字自动拆成“续行”，保留全部文字，续行不重复计算时长。开始和结束时间保存为 Excel 时间数值，按“分:秒”显示；时长为整数秒，其他文字不会作为公式执行。支持横向打印并重复表头。
- 替换、移除、播放错误及离开页面时释放视频预览资源，浏览器往返缓存保留页面时除外。
- 无远程脚本、字体、统计或 API；用户输入作为普通文本，不作为 HTML 执行。

## 验证

分镜版本已执行 JavaScript 语法检查；规则覆盖五类内容、5—600秒和两套版本，共5960组组合，核对逐镜时间连续、总时长正确且每镜均包含画面、旁白、字幕与剪辑说明。另检查文案顺序、禁止人声/字幕/音乐、缺失和不足素材、明确分段与重新生成。

分镜版本浏览器实测：新版示例填充、逐镜生成、旁白分配与待录音标记、重新生成保留旁白、复制后实际粘贴和时长校验；320、390、1024 像素宽度无横向溢出，未发现控制台错误。

表格版本已实测：生成前禁用导出、生成分镜行、编辑单元格后复制并实际粘贴、重新生成替换表格且保留需求、导出触发下载。

带格式导出版本已在浏览器实际下载常规和长文案 XLSX，检查压缩包与工作簿可读取、列宽、自动换行、行高、冻结表头、筛选与时间格式。常规示例13镜共30秒；3960字的单元格自动拆为14段续行，文字完整且时长没有重复累计。已渲染下载文件核对排版；未在 Excel / WPS 桌面应用中逐一打开验证。

本次检查 1440、1024、390、320 像素宽度，页面无横向溢出；大屏可完整展示各列，较窄屏幕在表格内部横向滚动，已实测手机宽度下编辑最右侧的剪辑说明并同步到复制文本。控制台未发现错误。

上一版本浏览器已验证视频选择、播放、替换、移除、格式不符、超大和损坏文件提示，本次继续复用该预览逻辑。未穷尽所有浏览器、真机设备和视频编码。

已检查 320、390、768、1024、1440 像素宽度，没有页面横向溢出；手机宽度使用单栏布局。这是浏览器尺寸模拟，未使用真实手机验证。

HTTP 模式在 127.0.0.1:8765 实测返回成功并完成上述浏览器检查。验证工具禁止打开 file: 协议，因此双击启动没有通过该工具实测；实现不含模块加载、外部请求或服务器依赖。

另通过模拟环境验证：自动复制不可用时选中正文并提示手动复制；替换、移除和离开页面会调用预览资源释放。这些为逻辑模拟检查，不等同于在所有真实浏览器中触发对应异常。
